# v0.3.0 库存体验

- 默认紧凑列表，可切换小方块或详细列表，选择仅保存在本设备。紧凑模式始终显示数量和临期状态，展开可编辑、消耗和删除。
- 添加或编辑库存可填写本批保质期天数，从入库日期起计算并显示到期日。仅影响这一批，默认保质期规则不变。
- 每批支持一组显式数量关系，例如3个，每个200克，共600克。关系属于批次；不同关系不自动合并。不猜测食材重量，不进行未声明的单位换算。推荐、结算预览、结算、手动消耗共用数量；混合单位需求不能重复占用。
- 设置页“导入基础库存”下方可导出库存码、二维码或固定格式 XLSX，支持粘贴库存码、选择二维码图片和 XLSX。二维码过大时提示使用库存码或表格；不调用外部服务。
- 导出全部非零普通库存和调味品；包括数量关系、日期、备注。仅传递库存，不是完整备份；完整备份入口保留。
- 一次最多2000行，文件最多5MB；固定11列。表头有说明批注。公式、超链接及特殊单元格拒绝导入。空到期日表示本批无到期日，不触发默认估算。
- 导入前逐行预览，新增食材会随新批次创建，现有食材的允许单位不自动修改。任意错误阻止整批导入。已有批次默认跳过并保留本机数量，不能用导入覆盖或同步数量；需调整的批次在库存页编辑。
- 预览的事务全部回滚，确认时重新校验；库存或食材配置改变需重新预览。确认导入在同一事务内完成。
- 安卓 Excel 使用系统保存窗口；二维码可截图保存，导入支持选择图片，暂不提供相机实时扫描。

验证：server/verify-v030-inventory.ts 使用独立临时库覆盖迁移、默认保质期保持、批次关系、真实扣减、混合单位占用、重复导入、预览回滚、错误回滚和过期批次往返。
